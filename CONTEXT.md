# TurnoCerto

Linguagem comum para a organização de escalas e dos acessos que as compartilham.

## Linguagem

**Espaço de gestão**:
Conjunto de escalas e pessoas que compartilham o mesmo acesso de gestão.
_Evitar_: Conta, organização, grupo de escalas

**Pessoa**:
Identidade de quem participa de uma ou mais escalas de um Espaço de gestão; não representa uma conta de acesso.
_Evitar_: Usuário

**Link de gestão**:
Credencial compartilhável que concede acesso de edição a um Espaço de gestão.
_Evitar_: Conta de administrador

**Link de leitura**:
Credencial compartilhável que concede consulta a semanas fixas de uma única escala.
_Evitar_: Link público
