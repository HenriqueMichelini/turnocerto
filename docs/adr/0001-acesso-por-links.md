# Acesso por links, sem cadastro obrigatório

O TurnoCerto prioriza a criação rápida de escalas por quem não quer passar por um cadastro. Por isso, um link privado de gestão concede edição a um Espaço de gestão, enquanto links de leitura separados dão acesso apenas às semanas escolhidas de cada escala. A alternativa de exigir conta facilitaria a recuperação e o controle individual de acesso, mas acrescentaria uma etapa antes do primeiro uso.

## Consequências

- Quem possui o link de gestão pode editar; ele deve poder ser substituído para invalidar uma cópia compartilhada por engano.
- Na primeira versão não há recuperação por e-mail; perder o link de gestão significa perder o acesso de edição. Se a recuperação opcional por e-mail for adicionada depois, ela substituirá o link anterior.
- Links de leitura são revogáveis, limitados a um período fixo de uma a quatro semanas, permanecem válidos até revogação e não exigem conta.
- Edições simultâneas não são colaborativas em tempo real: uma versão desatualizada não pode sobrescrever silenciosamente alterações posteriores.
